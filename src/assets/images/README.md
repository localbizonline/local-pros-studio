# Images

Photos and pictures the site imports. To see every image in the project at once, used or not, with the live pages
each one is on, open the image library: `image-library.html` at the project root
(http://localhost:4321/image-library.html with the dev server running). It is built by
`design/photo-library/build-image-library.py`; photos made for pages but not on the site are kept in
`design/photo-library/`.

Rules for new photos (DESIGN-SYSTEM.md section 5 and the site weight rules): real-looking photos in the site's
style, compressed before adding (webp, quality about 74), and a phone in a photo always shows a believable app
screen, never a blank one.
